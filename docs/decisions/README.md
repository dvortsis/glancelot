# Decisions

Written for: the lead and every session that needs to know why a rule exists.

Each decision gets its own file here, named `YYYY-MM-DD-<slug>.md`, one per pull request. Own files keep two PRs from colliding on a shared list. Earlier decisions are in `docs/WORK-QUEUE.yaml` (`lead_decisions` fields) and `docs/handoff/`.

Each file says what was decided, who decided it and why, in a few lines.
