## Building and testing in a cloud session

Until EN-02 lands, mirror the Dockerfile's `qt` and `build` stages (Ubuntu 24.04):

```bash
sudo apt-get update && sudo apt-get install -y --no-install-recommends build-essential cmake ninja-build python3-venv xvfb libgl1-mesa-dev libgl1-mesa-dri libxkbcommon-dev libfontconfig1 libdbus-1-3 libxcb-cursor0 libxcb-icccm4 libxcb-keysyms1 libxcb-shape0 libxcb-xinerama0 libxcb-image0 libxcb-render-util0 libxkbcommon-x11-0 libegl1 libglib2.0-0t64
python3 -m venv /tmp/aqt && /tmp/aqt/bin/pip install aqtinstall==3.3.0
/tmp/aqt/bin/aqt install-qt linux desktop 6.8.3 linux_gcc_64 -O "$HOME/Qt" -m qtshadertools --archives qtbase qtdeclarative qtshadertools
/tmp/aqt/bin/aqt install-qt linux desktop 6.8.3 linux_gcc_64 -O "$HOME/Qt" --archives icu
cmake -S . -B build-claude-<task> -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DCMAKE_PREFIX_PATH="$HOME/Qt/6.8.3/gcc_64"
cmake --build build-claude-<task> --parallel 4
QT_QPA_PLATFORM=offscreen ctest --test-dir build-claude-<task> --output-on-failure
```

**If `aqt` fails with a proxy 403** (the cloud network policy may block `download.qt.io` and its mirrors), use S1's proven fallback, conda-forge `qt6-main 6.8.3` (qtbase, qtdeclarative, qtshadertools), and say so in the handoff:

```bash

/tmp/bin/micromamba create -y -p /opt/qt683 -c conda-forge qt6-main=6.8.3
cmake -S . -B build-claude-<task> -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DCMAKE_PREFIX_PATH=/opt/qt683
```

## Handoff and review

- Handoff: `docs/handoff/<TASK>-HANDOFF.md` on the packet branch, then push the branch. Do not push `gate/*` and do not merge to `main`.
- Review: a fresh-context local reviewer on the lead's Windows PC (AGENTS.md, local lead topology) that implemented none of these packets writes `docs/verification/<TASK>-REVIEW.md` on branch `claude/review-<task>`, including the packet's targeted Windows tests.
- Windows feedback before review: check the `Build and test` workflow's `viewer` job (MSVC on `windows-2022`) for your branch push with `gh run list --branch <branch>` if `gh` is available; fix compile errors it reports before handing off.
- If the lead finds a Windows-only failure after your handoff, it arrives as a fresh cloud fix session on your branch or as a message the user pastes into your session.
- The lead batches approved packets into gates: first EN-03 + EN-05 + EN-06, then EN-02 + EN-04 (+ EN-08), then the four stack corrections.
